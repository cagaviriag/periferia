# T0.2 · Configuración

## Objetivo
Un único punto que lee el entorno y falla temprano con mensaje claro si falta algo.

## Trazabilidad
| Requisito | Fuente |
|---|---|
| Clave solo en variable de entorno del backend | PRD §8 Seguridad · C7 |
| Tope de iteraciones y de tokens configurables | PRD §8 Costo · CA1 · C6 |
| Timeout al proveedor LLM | PRD §8 Robustez |

## Comportamiento
1. Leer con `os.environ.get`. Valores por defecto: `OPENAI_MODEL=gpt-4o-mini`,
   `MAX_ITERACIONES=25`, `MAX_TOKENS_SESION=100000`, `LLM_TIMEOUT_SEGUNDOS=60`.
2. `raiz` = el directorio que contiene `app/`, resuelto desde `__file__`. **Nunca**
   una ruta absoluta escrita a mano.
3. Si `requiere_llm=True` y `OPENAI_API_KEY` está vacía o ausente, lanzar
   `ValueError("Falta OPENAI_API_KEY. Cópiala en .env siguiendo .env.example.")`
4. Si un valor numérico no es convertible a `int`, lanzar `ValueError` indicando
   **cuál** variable y qué valor recibió.
5. `resumen_publico` devuelve `{"provider": "openai", "model": ..., "max_iteraciones": ...}`.

## Casos de prueba
| Escenario | Esperado |
|---|---|
| Entorno sin `OPENAI_API_KEY`, `requiere_llm=True` | `ValueError` cuyo mensaje menciona `OPENAI_API_KEY` |
| Entorno sin `OPENAI_API_KEY`, `requiere_llm=False` | `Config` válida, `openai_api_key == ""` |
| `MAX_ITERACIONES="abc"` | `ValueError` que menciona `MAX_ITERACIONES` y `abc` |
| Entorno vacío, `requiere_llm=False` | defaults: modelo `gpt-4o-mini`, 25 iteraciones |
| `resumen_publico` con una clave presente | el dict resultante **no contiene** la clave en ningún valor |
| `config.raiz / "fixtures"` | existe en el disco |

El test de `resumen_publico` debe recorrer los valores del dict y afirmar que ninguno
contiene el valor de la clave. Es la verificación de C7.

Usa `monkeypatch.setenv` / `delenv`; no modifiques el entorno real del proceso.
