## Interfaz exacta (textual del PRD §7.4 — no la cambies)

```python
# app/sap/adapter.py
from typing import Protocol
from app.core.modelos import OrdenCompra

class SapAdapter(Protocol):
    async def consultar_proveedor(self, nit: str) -> dict[str, object] | None:
        """{"codigo_sap": str, "activo": bool} o None."""

    async def crear_orden(self, orden: OrdenCompra) -> dict[str, str]:
        """{"numero_oc": str, "fecha": str}."""

    async def buscar_orden_por_referencia(self, solicitud_id: str) -> dict[str, str] | None:
        """{"numero_oc": str} o None."""
```

Usa `Protocol`, no `ABC`: es tipado estructural y deja claro que el mock no hereda de
nada. El PRD exige que la interfaz exista para que el adaptador real de producción
(diseñado en `SOLUCION.md` §7.5) sea sustituible.

## `app/sap/mock.py`

```python
from pathlib import Path
from app.core.modelos import Maestros, OrdenCompra

NUMERO_INICIAL = 4500000001

class SapMock:
    def __init__(self, raiz: Path, maestros: Maestros) -> None: ...
    async def consultar_proveedor(self, nit: str) -> dict[str, object] | None: ...
    async def crear_orden(self, orden: OrdenCompra) -> dict[str, str]: ...
    async def buscar_orden_por_referencia(self, solicitud_id: str) -> dict[str, str] | None: ...
```

### Comportamiento

**`consultar_proveedor`** · cruza por NIT normalizado contra `maestros.proveedores`.
Devuelve `{"codigo_sap": ..., "activo": ...}` o `None`.

**`buscar_orden_por_referencia`** · lee `out/sap/ordenes.jsonl` línea por línea y
devuelve la primera cuyo `referencia.solicitud_id` coincida. Si el archivo no existe,
`None`. Una línea corrupta se ignora, no revienta.

**`crear_orden`** — el núcleo de la idempotencia (C10):
1. `existente = await buscar_orden_por_referencia(orden.referencia.solicitud_id)`.
2. Si existe → devolver **ese mismo número** sin escribir nada.
3. Si no: `numero = NUMERO_INICIAL + <cantidad de líneas válidas en ordenes.jsonl>`.
4. Escribir una línea con `{numero_oc, fecha, referencia, orden}` (la orden completa,
   serializada con `model_dump`).
5. Devolver `{"numero_oc": str(numero), "fecha": <ISO del día>}`.

El destino **siempre** sale de `ruta_salida(raiz, "sap", "ordenes.jsonl")`. No construyas
la ruta a mano: es la mitigación del defecto **D7** del informe de QA de la Fase 0.

**Quién reporta `idempotente`:** el mock devuelve solo `{numero_oc, fecha}`, como manda
el PRD. La bandera `idempotente` la calcula `oc_crear` (T2.2) comparando si hubo
búsqueda previa exitosa. No la agregues a la interfaz.

### Métodos `async`
La interfaz del PRD los declara `Promise<...>`, así que son `async` aunque el mock no
haga I/O asíncrono real. Eso es deliberado: el adaptador de producción (OData o RFC)
sí será asíncrono, y la firma no debe cambiar al sustituirlo.

## Casos de prueba
| Escenario | Esperado |
|---|---|
| `crear_orden` en `out/` limpio | `numero_oc == "4500000001"` (I2) |
| Dos órdenes distintas | `4500000001`, luego `4500000002` |
| **`crear_orden` dos veces con el mismo `solicitud_id`** | mismo número, y `ordenes.jsonl` con **una sola** línea (I3) |
| `buscar_orden_por_referencia` de un id inexistente | `None` |
| `buscar_orden_por_referencia` sin archivo | `None`, sin excepción |
| `ordenes.jsonl` con una línea corrupta (`{roto`) | se ignora; las válidas se siguen leyendo |
| `consultar_proveedor("900.555.111-2")` | `{"codigo_sap": "100234", "activo": True}` — cruza con puntos y dígito de verificación |
| `consultar_proveedor("901777888")` | `activo: False` (Consultores Ágiles) |
| `consultar_proveedor("999999999")` | `None` |
| La ruta de escritura | el archivo cae bajo `out/sap/`, verificado con la ruta resuelta |

Usa `tmp_path` como `raiz` en todos los tests y los maestros reales de `fixtures/`.
Los tests `async` necesitan `asyncio.run(...)`: **no agregues `pytest-asyncio`**, que
no está en las dependencias.
