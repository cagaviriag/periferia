# T0.5 · Bitácora y log de control

## Objetivo
Dos registros obligatorios del PRD: la bitácora técnica de toda llamada a herramienta
y el log de control que consume auditoría.

## Trazabilidad
| Requisito | Fuente |
|---|---|
| Toda llamada a herramienta queda en `out/log.jsonl` | PRD §6.3 CA4 · C8 |
| Fila en `out/control.csv` por **cada intento**: exitoso, bloqueado o pendiente | PRD §5 HU-5 · oráculo I6 |
| Columnas: `solicitud_id, resultado, numero_oc, retroactiva, bloqueos, confirmaciones, ts` | PRD §5 HU-5 (textual) |
| La clave nunca aparece en logs | PRD §8 Seguridad · C7 |

## Dependencias
T0.3 (usa `ruta_salida`, `agregar_linea_jsonl`).

## Archivos
| Archivo | Acción |
|---|---|
| `app/core/log.py` | crear |
| `tests/test_log.py` | crear |

## Firmas exactas

```python
from pathlib import Path
from typing import Any, Literal

ResultadoIntento = Literal["creada", "bloqueada", "pendiente_confirmacion", "idempotente", "error"]

def registrar_herramienta(
    raiz: Path,
    herramienta: str,
    ok: bool,
    resumen: str,
    caso: str | None = None,
) -> None:
    """Agrega una línea a out/log.jsonl (CA4).

    Formato: {"ts", "herramienta", "caso", "ok", "resumen"}.
    `resumen` es una frase corta, NUNCA el payload completo ni datos sensibles.
    Esta función no lanza: si el log falla, el flujo continúa.
    """

def registrar_control(
    raiz: Path,
    solicitud_id: str,
    resultado: ResultadoIntento,
    numero_oc: str | None,
    retroactiva: bool,
    bloqueos: list[str],
    confirmaciones: list[str],
) -> None:
    """Agrega una fila a out/control.csv (HU-5).

    Crea el archivo con encabezado si no existe. `bloqueos` y `confirmaciones`
    se serializan como códigos separados por ';' (ej. "RC2;RC4"), vacío si no hay.
    Esta función no lanza.
    """
```

## Comportamiento

### `registrar_herramienta`
1. `ts` en ISO 8601 con `datetime.now(timezone.utc).isoformat()`.
2. Ruta: `ruta_salida(raiz, "log.jsonl")`.
3. Envolver todo en `try/except Exception: pass`. Un fallo de bitácora **no** puede
   romper una herramienta (C3).

### `registrar_control`
1. Encabezado exacto, en este orden:
   `solicitud_id,resultado,numero_oc,retroactiva,bloqueos,confirmaciones,ts`
2. Escribir con el módulo `csv` de la librería estándar, **no** con `join(",")`:
   las descripciones y detalles pueden contener comas.
3. `numero_oc` vacío si es `None`. `retroactiva` como `true`/`false` en minúsculas.
4. Modo `"a"` con `newline=""`. Encabezado solo si el archivo no existía.
5. Envolver en `try/except Exception: pass`.

## Casos de prueba
| Escenario | Esperado |
|---|---|
| `registrar_herramienta` tres veces | `out/log.jsonl` con 3 líneas, cada una JSON válido con las 5 claves |
| `registrar_control` primera vez | archivo con encabezado + 1 fila de datos |
| `registrar_control` tres veces | encabezado **una sola vez**, 3 filas de datos |
| `bloqueos=["RC2","RC4"]` | la celda contiene `RC2;RC4` |
| `bloqueos=[]` | la celda queda vacía |
| `numero_oc=None` | la celda queda vacía |
| Un detalle con coma: `bloqueos=["RC5: 25.000.000, no 26.500.000"]` | al releer con `csv.reader`, la fila tiene exactamente 7 columnas |
| Ruta de `out/` no escribible (simulada con monkeypatch que lanza) | **no** propaga excepción |
| Los 6 casos del oráculo registrados | `out/control.csv` con 6 filas de datos (I6) |

El test de la coma es el que importa: demuestra por qué se usa el módulo `csv`.
