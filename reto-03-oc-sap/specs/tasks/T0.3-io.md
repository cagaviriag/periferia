# T0.3 · Entrada/salida de archivos

## Objetivo
Toda lectura de fixtures y toda escritura pasan por aquí, con la garantía de que
**nada se escribe fuera de `out/`**.

## Trazabilidad
| Requisito | Fuente |
|---|---|
| `fixtures/` solo lectura; `out/` escritura | PRD §6.1 diagrama · C1 |
| Rutas resueltas desde `ctx.directory`, nunca absolutas | PRD §6.2 |
| `out/` se limpia al inicio | PRD §8 Determinismo · C9 |
| Las herramientas no ejecutan comandos de shell | PRD §8 Seguridad |

## Dependencias
T0.2 (usa `Config.raiz`).

## Archivos
| Archivo | Acción |
|---|---|
| `app/core/io.py` | crear |

## Firmas exactas

```python
from pathlib import Path
from typing import Any

class RutaInvalidaError(Exception):
    """Se intentó escribir fuera de out/."""

def ruta_fixture(raiz: Path, *partes: str) -> Path:
    """Construye una ruta dentro de fixtures/. No verifica existencia."""

def ruta_salida(raiz: Path, *partes: str) -> Path:
    """Construye una ruta dentro de out/, creando los directorios padre.

    Lanza RutaInvalidaError si el resultado resuelto cae fuera de out/.
    """

def leer_json(ruta: Path) -> dict[str, Any] | list[Any] | None:
    """Lee y parsea JSON. Devuelve None si el archivo no existe.

    Si el JSON está malformado, lanza ValueError con un mensaje que incluye
    el nombre del archivo. El llamador (una herramienta) lo convierte en
    {"ok": false, "error": ...}.
    """

def leer_texto(ruta: Path) -> str | None:
    """Lee un archivo de texto en UTF-8. Devuelve None si no existe."""

def escribir_json(ruta: Path, datos: object) -> Path:
    """Escribe JSON indentado con ensure_ascii=False. Devuelve la ruta."""

def escribir_texto(ruta: Path, contenido: str) -> Path:
    """Escribe texto UTF-8. Devuelve la ruta."""

def agregar_linea_jsonl(ruta: Path, registro: dict[str, Any]) -> None:
    """Agrega una línea JSON al final del archivo."""

def limpiar_salida(raiz: Path) -> None:
    """Borra el contenido de out/ para garantizar determinismo (C9).

    Solo borra dentro de out/. Si out/ no existe, la crea.
    """
```

## Comportamiento

### Validación de ruta — el control crítico
`ruta_salida` debe:
1. Construir `destino = (raiz / "out").joinpath(*partes)`.
2. Resolver ambas con `.resolve()`.
3. Verificar que `out` resuelto sea ancestro de `destino` resuelto
   (`destino.is_relative_to(out_resuelto)`).
4. Si no lo es → `RutaInvalidaError` con la ruta ofensiva en el mensaje.
5. Solo entonces `destino.parent.mkdir(parents=True, exist_ok=True)`.

Esto bloquea `..` y rutas absolutas. **Es el único punto del sistema que autoriza
escritura**, así que no se puede omitir.

### `limpiar_salida`
Itera el contenido de `out/` y borra archivos y directorios. Nunca borra `out/` misma
ni toca nada fuera. No uses `shutil.rmtree` sobre `raiz`.

## Casos de prueba
| Escenario | Esperado |
|---|---|
| `ruta_salida(raiz, "sol-001", "payload.json")` | ruta bajo `out/sol-001/`, padre creado |
| `ruta_salida(raiz, "..", "escape.txt")` | `RutaInvalidaError` |
| `ruta_salida(raiz, "../../etc/passwd")` | `RutaInvalidaError` |
| `ruta_salida(raiz, "/etc/passwd")` | `RutaInvalidaError` |
| `leer_json` de un archivo inexistente | `None` |
| `leer_json` de un archivo con `{"roto":` | `ValueError` cuyo mensaje incluye el nombre del archivo |
| `leer_json` de `fixtures/reto-03/maestros/proveedores.json` | lista de 5 elementos |
| `leer_texto` de `fixtures/.../sol-001/cotizacion.txt` | contiene `"COT-TS-2026-0451"` |
| `escribir_json` + `leer_json` con acentos (`"Papelería"`) | ida y vuelta idéntica |
| `agregar_linea_jsonl` tres veces | archivo con 3 líneas, cada una JSON válido |
| `limpiar_salida` con archivos y subdirectorios en `out/` | `out/` existe y está vacía |
| Intentar escribir en `fixtures/` | falla (el directorio está en solo lectura) |

El test de escape de rutas es obligatorio y debe cubrir los tres vectores: `..`,
ruta absoluta, y `..` anidado.
