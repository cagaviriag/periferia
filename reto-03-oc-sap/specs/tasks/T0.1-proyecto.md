# T0.1 · Esqueleto del proyecto Python

## Objetivo
`uv sync` instala el entorno y `mypy --strict app/` corre sin errores de configuración.

## Trazabilidad
| Requisito | Fuente |
|---|---|
| Arranque en < 2 min en máquina limpia | PRD §8 Arranque |
| `.env.example` con variables requeridas, sin valores | PRD §6.5, §9.2 |
| Dependencias justificadas | PRD §8 Dependencias |
| Pydantic sustituye a `zod`; `mypy --strict` sustituye a "sin `any`" | ADR-001 |
| Sin LangChain ni LangGraph | ADR-002 |

## Dependencias
Ninguna. Es la primera tarea.

## Archivos
| Archivo | Acción |
|---|---|
| `pyproject.toml` | crear |
| `.env.example` | crear |
| `app/__init__.py`, `app/core/__init__.py`, `app/tools/__init__.py`, `app/llm/__init__.py`, `app/sap/__init__.py` | crear vacíos |
| `tests/__init__.py` | crear vacío |

**Prohibido tocar:** `fixtures/`, `specs/`, cualquier otro archivo.

## Contenido de `pyproject.toml`

```toml
[project]
name = "reto-03-oc-sap"
version = "1.0.0"
description = "Agente conversacional de Órdenes de Compra SAP — Periferia IT Group"
requires-python = ">=3.12"
dependencies = [
    "pydantic>=2.9",      # valida argumentos de herramientas (sustituye a zod)
    "openai>=1.54",       # SDK del proveedor LLM
    "fastapi>=0.115",     # API del chat
    "uvicorn>=0.32",      # servidor ASGI
    "streamlit>=1.40",    # front de chat
    "httpx>=0.27",        # cliente HTTP del front hacia la API
]

[dependency-groups]
dev = ["pytest>=8.3", "mypy>=1.13", "ruff>=0.7"]

[tool.mypy]
python_version = "3.12"
strict = true
warn_unreachable = true
disallow_any_explicit = true

[tool.pytest.ini_options]
testpaths = ["tests"]
pythonpath = ["."]

[tool.ruff]
line-length = 100
target-version = "py312"
```

**No agregues dependencias que no estén en esta lista.** Cada una está justificada
arriba y se replica en `SOLUCION.md`.

## Criterios de aceptación
- [ ] `uv sync` termina sin error
- [ ] `uv run mypy --strict app/` corre (sin archivos aún, debe salir limpio)
- [ ] `uv run pytest` corre (sin tests aún, 0 collected, exit 0 o 5)
- [ ] `.env` **no** existe en el repositorio y está en `.gitignore`
- [ ] `.env.example` no contiene ningún valor de clave

## Fuera de alcance
No escribas código de aplicación. Solo el esqueleto y la configuración.
